## 📱 App para iPhone e Android

O Capacitor empacota o site como aplicativo instalado. `pnpm run cap:sync` copia os arquivos atuais do site para `www/` e atualiza os projetos nativos em `ios/` e `android/`.

### Preparar e compilar

1. Instale Node.js 22 ou superior e pnpm; rode `pnpm install`.
2. Para Android, use Android Studio e rode `pnpm run android`.
3. Para iPhone, rode `pnpm run ios` em um Mac com Xcode 26 ou superior.
4. Sem Mac, conecte o projeto a um serviço de build iOS na nuvem. Para instalar via TestFlight, também será necessário configurar o App Store Connect e a assinatura Apple.

Os arquivos de `www/` são gerados automaticamente; edite os arquivos do site na raiz e rode `pnpm run cap:sync` para atualizar as plataformas.

### Instalar no seu iPhone sem assinatura paga

O workflow `ios-personal-install` em `codemagic.yaml` compila uma versão iOS sem assinatura de distribuição. Depois do build, baixe `OurLoveStory-unsigned.ipa` e use AltStore/AltServer ou Sideloadly no Windows para assinar com sua Apple Account gratuita e instalar no seu iPhone.

Apps assinados com uma conta gratuita precisam ser renovados a cada 7 dias. Com AltStore, mantenha AltServer aberto no PC e o iPhone na mesma rede Wi-Fi para atualizar a assinatura; com Sideloadly, ative a renovação automática. Uma Apple Account gratuita permite até 3 apps instalados ao mesmo tempo.

O Codemagic oferece 500 minutos de build macOS por mês no plano individual gratuito. O build em nuvem precisa que o projeto esteja em um repositório Git conectado ao Codemagic; mantenha-o privado por causa das fotos e dados pessoais do projeto.
